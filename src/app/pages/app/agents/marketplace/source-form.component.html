A source is the address of a catalog of agents. It is read when it is saved, and kept as it was read: nothing in it runs until an agent is reviewed and installed.

A new address needs its credential again: it is never sent anywhere it was not given for.

Saving with None removes the credential this source is read with now.

What a catalog is

The address answers one JSON document listing the agents on offer: each with its manifest, and for each machine it runs on, the address of its program with that file's size and digest. Sample data and a readme can be listed beside them.

The manifest declares what the agent can do, the level of each function, what it keeps and where it connects. That is what an administrator reviews, and reading a catalog runs nothing. Installing keeps one exact version: what is downloaded must match its digest, and a version never changes.
